# JavaScript Problem-Solving with UI ⚡

This repository is all about solving **JavaScript coding questions** but in an **interactive way**.  
Instead of hardcoding inputs, all parameters are handled from the **UI (forms, buttons, etc.)**, making it more practical and user-friendly.  

## 📂 What’s inside?
- 🔄 String problems (reverse string, palindrome, etc.) with UI input  
- 🔢 Number problems (fibonacci series, prime numbers, factorial, etc.) via forms  
- 🔎 Searching & sorting algorithms (binary search, selection sort, etc.) with user-controlled input  
- 🎮 Mini logic projects (Snake-Water-Gun, guess-the-number, etc.) — fully interactive  
- 🛠️ More UI-based challenges coming soon…  

## 🚀 Goals
- Practice JavaScript **problem-solving with real-world interaction**  
- Improve skills in **DOM manipulation & event handling**  
- Build mini projects where logic meets UI  

## ✅ Progress
- ✔️ 60+ problems & projects done with UI support  
- 🚧 Adding more challenges regularly
